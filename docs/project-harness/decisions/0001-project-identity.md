## 决策

Canonical 产品名为 **Demiurges**。repository slug 为 `demiurges`，本地仓库路径为 `/Users/Admin/projects/Demiurges`，技术描述为 **A World Agent Harness**。

主标语为：

> **造物，从此不再唯一。**<br>
> **Worldmaking, no longer singular.**

## 含义

复数名称表达：造物不再只属于唯一神祇、模型、实验室或平台。Demiurges 为多个模型和用户提供显式工程环境，让他们能够创建和推演世界。

这个名字不意味着全知。被创造的世界可能不完整，也可能错误；versioning、explicit evolution、evidence、evaluation 与 recovery 正是因为每个 worldmaker 都可能犯错而存在。

## 已知命名风险

一款无关的独立游戏使用了相同复数单词。Human 已明确接受有限的搜索冲突。正式 trademark、organization、package scope 和 domain clearance 仍属于未来独立的 business action。
